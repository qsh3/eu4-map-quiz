# EU4 纯度测试

一个基于《欧陆风云 4》世界地图的答题游戏，测测你对这张地图有多熟。

**🔗 在线试玩：https://qsh3.github.io/eu4-map-quiz/**

---

## 两种玩法

### 猜地块

题目给出一个地名，你要在世界地图上点出它对应的那块地。

> 例：题面显示「君士坦丁堡」，你在地图上找到并点击它。

### 猜国家

题目给出一面国旗和国家名，你要在地图上点出这个国家的任意一块领土。

> 例：题面显示奥斯曼的旗帜，你点中它版图内的任意一块地即可。

---

## 开始前的设置

| 选项 | 说明 |
|---|---|
| **题量** | 正常 10 题 / 挑战 30 题 / 噩梦 50 题 / 完全（把题库做穿） |
| **题库范围** | 全部，或只挑某几个区域出题（可多选） |
| **每题限时** | 不限时，或 10 / 20 / 30 秒 |
| **国家筛选** | 仅猜国家模式有效：默认只出 1444 年真实存在的国家，也可放开包含可成立国家 |

---

## 操作方式

- **拖动**地图平移，**滚轮**或**双指捏合**缩放，右下角「复位」回到全图
- **点击**地块即为作答
- 按 **空格**进入下一题

---

## 答题反馈

- 答对 —— 地块变**青绿色**
- 答错或超时 —— 地块变**粉红色**
- 每道题结算后，正确位置会一直留在地图上，方便记忆

图例见页面底部：

| 颜色 | 含义 |
|---|---|
| 白色 | 本题库范围内、尚未作答 |
| 青绿 | 答对 |
| 粉红 | 答错 / 超时 |
| 灰色 | 本次不出题的国家 |
| 土色 | 未殖民地区 |
| 深灰 | 不可通行区域（高山、沙漠） |
